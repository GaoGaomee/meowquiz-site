# meowquiz-site

喵喵刷题 / MeowQuiz（Android，`com.meowquiz.app`）的公开网页，用 GitHub Pages 发布：

- `index.html`：首页
- `privacy.html`：隐私政策（中文在前，英文在后）
- `delete-account.html`：删除账号说明（中英双语）

这个仓库只放公开网页，不放 App 代码、密钥或任何内部资料。纯静态 HTML，没有外部脚本、统计或追踪。

联系邮箱：meowquizofficial@gmail.com

This repository only holds the public web pages for MeowQuiz (privacy policy and account deletion). No app code, secrets or internal material.
